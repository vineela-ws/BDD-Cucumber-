# BDD-Cucumber-

BDD-Cucumber Framework
This repository demonstrates a Behavior-Driven Development (BDD) test automation framework using Cucumber with Selenium WebDriver, Juni and Java.
It follows the Page Object Model (POM) design pattern and enables readable, maintainable, and scalable automated tests.

🚀 Features
✅ BDD-style test cases with Gherkin syntax
🔧 Integration with Selenium WebDriver
🧪 Junit for test execution and reporting
🗂️ Page Object Model for clean code structure
📋 Centralized configuration management
📊 Easily extendable for reporting and logging

🛠️ Technology Stack

| Tool/Library       | Purpose                    |
| ------------------ | -------------------------- |
| Java               | Programming language       |
| Selenium WebDriver | Browser automation         |
| Cucumber           | BDD with Gherkin syntax    |
| Junit            | Test orchestration         |
| Maven              | Dependency management      |
| Log4j              | Logging                    |
| Page Factory       | Web element initialization |
